# v1.0.3

Улучшен выбор получателей и полноценный ответ на согласие в MAX.

## Что изменилось

**Выбор получателей: понятные метки и список при открытии.** Общий компонент выбора чатов
(`Support\ChatSelectionField`, используется в форме создания рассылки и в сегментах) теперь показывает список
получателей сразу при открытии — а не только строку поиска: опции подгружаются серверно (активные чаты по убыванию
активности, лимит 50, дедуп по `chat_id`, eager-загрузка профиля пользователя без N+1). Метка каждой опции переработана:
бейдж типа чата («Диалог»/«Группа»/«Канал») + имя получателя + серый суффикс `(ID: …)`. Имя для диалога берётся из
профиля `max_users` (name → first+last → username), для групп/каналов (названий в реестре нет) — честный фолбэк на
`chat_id`; при переопределении `chats_model` с полем `title` приоритет у него. Поиск расширен: кроме `chat_id` теперь
ищет и по имени (first/last/name/username). Метки рендерятся через `allowHtml()` и безопасно экранируются (`e()`) —
нестандартный `chat_type` нормализуется в «Чат» без вывода сырой строки.

**Согласие: кнопки убираются, в чат приходит подтверждение.** Раньше на нажатие кнопки «Согласен»/«Не согласен»
отвечало только всплывающее уведомление, а кнопки оставались висеть. Теперь слушатель `HandleConsentCallback`:
убирает inline-кнопки из исходного сообщения через `editMessage` (текст опроса при этом сохраняется — MAX-овский
`PUT /messages` заменяет тело целиком); отправляет в чат отдельное подтверждающее сообщение — «Вы согласились на
получение рассылок.» либо «Вы отказались от получения рассылок.»; отвечает на callback тем же текстом через
`sendAnswer`. Каждая операция изолирована try/catch с логированием без чувствительных данных, а если текст опроса
недоступен в апдейте — edit аккуратно пропускается, подтверждение всё равно уходит.

## Изменения схемы и конфигурации

Схема БД не менялась. В конфиге ключ `consent.answer_notification` заменён на два отдельных текста:
`answer_notification_opt_in` и `answer_notification_opt_out` (с прежними русскими значениями по умолчанию). В
`lang/{ru,en}` добавлен блок `chat_types` для подписей бейджей. Новых `FILAMENT_MAX_BROADCASTS_*` env-переменных нет.

## Тесты

154 теста (442 assertions). Доработан `ChatSelectionFieldTest` (метки с бейджами и именами, список при открытии,
поиск по id и имени, дедуп, XSS-экранирование raw-фолбэка, нормализация неизвестного типа). Расширен
`HandleConsentCallbackTest`: opt-in/opt-out проверяют три вызова MAX (edit без кнопок и с сохранённым текстом,
отправка подтверждения, answer с callback_id) и тексты сообщений; добавлен тест graceful degradation при
недоступном тексте опроса. PHPStan level max — без ошибок, PSR-12, `declare(strict_types=1)`. CI
(`github/workflows/ci.yml`): lint, PHPStan, PHPUnit, `composer audit`.
