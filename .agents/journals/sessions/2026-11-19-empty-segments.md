# Пустые сегменты — допустимое состояние

## Проблема

В остаточных замечаниях ревью был пункт: «Выбрать всех» при отсутствии активных чатов даёт пустой список, и сегмент
можно сохранить пустым. Проверка «после разворачивания не пусто» предлагалась как исправление.

## Решение

Пустые сегменты — осознанно поддерживаемое состояние: сегмент создаётся заранее и наполняется позже, стартовый сегмент
«Новости и акции» тоже создаётся пустым, поле получателей в форме сегмента необязательное. Поэтому проверку не
добавляем:
пустой сегмент валиден, а рассылка по нему отклоняется на уровне `BroadcastService`/`SegmentConsentRule`, пока не
появятся согласившиеся. В селект рассылки пустой сегмент не попадает (`consentedCounts()` равно нулю).

Пункт 4 плана остаточных замечаний закрыт как «не дефект»; в README и `AGENTS.md` (gotcha 27) добавлено пояснение.

## Тесты

Код не менялся, тесты не добавлялись. Текущий набор: 342 теста / 943 утверждения.

## Нюансы

- «Выбрать всех» без активных чатов по-прежнему разворачивается в пустой список — это ожидаемо для пустого сегмента.
- Для рассылки пустой сегмент бесполезен: сервис бросает `InvalidArgumentException`, форма не даёт выбрать такой
  сегмент.
