## Проблема

Ядро `max-php-client` и адаптер `laravel-max-client` перешли на v2.0.0: `Update` — типизированная иерархия, enum
`UpdateType`/`AttachmentType`/`ButtonType` удалены, `InlineKeyboardButtonRow` заменён `Keyboard`, `sendAnswer`
переименован в `answerCallback`. Плагин собирался под плоскую модель v1.1.8.

## Решение

- `composer.json`: `dev-new` для адаптера и ядра из Packagist (path-repositories не используются).
- `HandleConsentCallback`: принимает `MessageCallbackUpdate`; `chat_id` — из `message.recipient`, пользователь — из
  `callback.user` или отправителя, `message_id` — из `message.body.mid`.
- Кнопки: `Keyboard`/`CallbackButton`/`LinkButton`; контракт `buttonRows()` возвращает `list<list<Button>>`.
- Вложения: `Photo/Video/Audio/FileAttachmentRequest` + `InlineKeyboardAttachmentRequest`, `UploadEndpoint` → token.
- Ответ на callback — `answerCallback()`.

## Тесты

PHPUnit 302/302 (819 assertions). Тесты кнопок переведены на массивы кнопок; payload'ы callback-апдейтов приведены к
v2-форме (`callback.message` вместо верхнеуровневых `chat_id`/`message_id`/`user`). Callback без сообщения теперь
игнорируется — тесты отражают это.

## Нюансы

- `dev-new` — движущаяся цель, только для предрелизной проверки; после тегов `v2.0.0` — `^2.0`.
- `symfony/*` и `laravel/framework` обновлены (advisories 5 → 0).
- Серверная проверка вебхуков в тестовом проекте не пройдена; релиз отложен.
