# «Выбрать всех» в получателях не обходит согласие

## Проблема

«Выбрать всех» в получателях рассылки подставляло все активные чаты реестра, а явный список получателей отправлялся как
есть. При выбранных сегментах это обходило согласие: достаточно было нажать «Выбрать всех» или добавить чат вручную,
чтобы рассылка ушла тем, кто не давал `opt_in`.

## Решение

- `ChatSelectionField::make(..., selectAllIds: Closure(Get): array)`: «Выбрать всех» разворачивается в контекстный
  список. В форме рассылки при выбранных сегментах это `consentedChatIds()` этих сегментов, без сегментов — все активные
  чаты. В сегменте осталось прежнее поведение: все активные диалоги.
- `BroadcastService::resolveChats()`: при наличии сегментов объединение `opt_in`, а явные `chatIds` пересекаются с ним.
  Ручной список сужает аудиторию, но не расширяет; без сегментов явный выбор работает как раньше.
- Снимок `recipient_chat_ids` теперь сохраняет фактических получателей (отфильтрованных и активных), а не сырой список.
- `SegmentConsentRule` больше не пропускает проверку из-за ручного списка получателей: сегмент без `opt_in` отправить
  нельзя.
- Хелперы селектов и модалки обновлены в `lang/ru` и `lang/en`.

## Тесты

342 теста / 943 утверждения. Обновлены тесты выбора всех и сегментных рассылок; добавлены: «Выбрать всех» при сегменте
даёт только согласившихся, явный список не расширяет сегментную аудиторию, `expandState` с контекстным списком, снимок
получателей содержит фактический список.

## Нюансы

- Явный чат, добавленный вручную к сегментной рассылке, молча отбрасывается, если у него нет `opt_in`: это следует из
  «рассылка по сегменту — только согласившимся». Для рассылки без сегментов ручной выбор не ограничен.
- `SegmentConsentRule` проверяет только сегменты; при пустом выборе сегментов её результат не важен.
- Пункт закрыт в плане остаточных замечаний; следующие пункты (полный резолв реестра в опросе, батчинг предзаполнения,
  пустой «Выбрать всех») остаются.
