# Приватный диск вложений и закрытие плана

## Проблема

Пункт 3 плана: `image.disk` по умолчанию `public`, поэтому загруженные картинки и файлы рассылки доступны по HTTP, хотя
нужны только для `uploadMedia` — в MAX их дальше отдают серверы мессенджера. Пункт 4 (сверка README и конфига) по факту
был выполнен, но не отмечен.

## Решение

- Дефолт `image.disk` переведён с `public` на `local` (`storage/app/private`). Описано в конфиге, `.env.example`, README
  («Вложения и приватность»), `AGENTS.md` (A02, A04, gotcha 29).
- Новый `Support\AttachmentStorage`: `disk()`, `isPublicDisk()`, `url()`. Публичный диск отдаёт обычный URL, приватный —
  временную подписанную ссылку на 30 минут; при отсутствии файла или поддержке временных ссылок возвращается null.
- `BroadcastForm` показывает превью и ссылки через хелпер; `BroadcastSender` берёт диск из того же места. Поле «Файлы»
  получило белый список `image.accepted_file_types` (pdf, doc (x), xls (x), ppt (x), txt, csv, zip), картинки — MIME из
  `image.accepted_mime_types`.
- В Testbench включён `filesystems.disks.local.serve = true`, как в скелете Laravel 11+: иначе временные ссылки на
  локальном диске не строятся.

## Тесты

316 тестов / 863 утверждения (было 302/819). Новые: `tests/Unit/Support/AttachmentStorageTest.php` (9 тестов:
публичный/приватный диск, пустой и неизвестный диск, отсутствующий файл, диск без временных ссылок), отправка вложения с
дефолтного приватного диска (`BroadcastSenderTest`), превью и подписанные ссылки на странице просмотра, отсутствующий
файл без ссылки, приём pdf через форму и белый список поля «Файлы».

## Нюансы

- `Storage::fake()` всегда подменяет `temporaryUrl` замыканием, поэтому ветка «диск не умеет временные ссылки»
  проверяется на настоящем диске без `serve`.
- Filament валидирует MIME только у `TemporaryUploadedFile`; в тестах правило проверяется через
  `getAcceptedFileTypes()`, иначе негативный тест зелёный вхолостую.
- `mimetypes` проверяет содержимое, а не расширение: `.php` с текстом проходит как `text/plain`. Риск снижен тем, что
  диск приватный и файлы не раздаются веб-сервером.
- План закрыт: заголовок «выполнен», пункты 1–4 отмечены `(готово)`, в «Готово» добавлена запись. Релизный блок v2.0.0
  (теги ядра, вебхуки, Gate в CI) остаётся в журнале 2026-11-17 и release notes.
- Дрейф версий воспроизведён и закрыт: локально Filament v5.11.0, в чистой установке v5.11.4, где
  `Filament::getPanel()` объявлен `Panel|null`. Тест плагина получает панель через приватный хелпер с явным
  `/** @var Panel|null */` и `assertInstanceOf` — так анализ проходит на обеих версиях без baseline.
- Локальная версия PHPStan с `treatPhpDocTypesAsCertain` ругалась на `assertNotNull()` для не-null типа, поэтому
  проверка типа вынесена в `assertInstanceOf()` с локальным `@var`, а не в `assertNotNull()`.
