# «Выбрать всех» внутри селекта и починенный ключ локализации

## Проблема

На странице создания и редактирования сегмента вместо кнопки «Выбрать всех» показывался сырой ключ
`filament-max-broadcasts::broadcasts.chat_selection.select_all`. Причина — блок `chat_selection` в `lang/ru` и
`lang/en` оказался вложен внутрь `chat_types`: ключа верхнего уровня не существовало, и `__()` возвращал строку как
есть. Заодно действие «Выбрать всех» было вынесено отдельной кнопкой рядом с полем, а не в самом выпадающем списке.

## Решение

- `chat_selection` вынесен на верхний уровень обоих lang-файлов.
- `ChatSelectionField`: вместо `hintAction` добавлено служебное значение `SELECT_ALL` первым вариантом в списке — сразу
  под полем поиска. Подпись — HTML-строка с переводом. При сохранении `dehydrateStateUsing` разворачивает его в
  `allIds($dialogsOnly)`: для получателей — все активные чаты, для сегмента — только диалоги. Значение не попадает в БД.
- `optionLabels()` умеет показывать служебное значение (чип «Выбрать всех»), `DialogsOnlyRule` его игнорирует.
- Поиск работает как раньше: при вводе подгружаются результаты, «Выбрать всех» остаётся в списке без поиска.

## Тесты

341 тест / 940 утверждений. Обновлены: опции и подписи `ChatSelectionField` (служебное значение первым, метка,
`expandState`), выбор всех в форме рассылки и в форме сегмента — теперь через `fillForm()` + `create()` и проверку
сохранённых получателей/сегмента, а не через удалённое действие. Добавлены проверки `optionLabels` и `expandState`, а
также что вариант «Выбрать всех» считается явным выбором получателей для правила сегментов.

## Нюансы

- «Выбрать всех» — это опция списка, а не строка в шапке списка: Choices.js не поддерживает произвольную кнопку внутри
  выпадающего меню без кастомного JS. Опция визуально выделена и стоит первой под поиском.
- В сегменте «Выбрать всех» выбирает только диалоги, в получателях — любые активные чаты; на это влияет `dialogsOnly`.
- Служебное значение не проходит в валидацию и БД: `DialogsOnlyRule` его пропускает, `dehydrateStateUsing` заменяет
  списком id.
