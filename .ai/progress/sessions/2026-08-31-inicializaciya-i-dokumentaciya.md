# Сессия [2026-08-31] — Инициализация проекта и базовой документации

## Контекст
Начало работы над автономным Filament-плагином `geekcodev/filament-max-broadcasts` — массовые рассылки пользователям
MAX внутри Filament-панели. Проект ведётся как чистый пакет с нуля.

## Что сделано
- Составлен и финализирован рабочий план `PLAN-filament-max-broadcasts.md` (§0–§13): решения, цели, структура, конфиг,
  миграции, классы, Filament-ресурс, тесты, Gate, пошаговый чек-лист из 22 шагов.
  План — вспомогательный файл сессии, в git не пойдёт и будет удалён после переноса задач в кодовую базу.
- Создан `AGENTS.md` — проектный контекст и правила для агентов: описание плагина, git-процесс, правила ИИ-агентов,
  структура репозитория, архитектура и контракты, локальная разработка через Docker, обязательный Gate, OWASP Top 10,
  источник истины MAX API.
- Заведён журнал прогресса `.ai/progress/` (единый `JOURNAL.md` + файлы сессий в `sessions/`).

## Принятые решения
- Плагин **самодостаточный с нуля**, в git-файлах нет упоминаний внешних хост-проектов — проект чистый, понятен при
  новом `git clone`.
- Таблицы с префиксом `max_`: `max_broadcasts`, `max_broadcast_recipients` — во избежание конфликтов с именами,
  которые могут быть заняты в хост-проекте.
- Кнопки-диплинки акций — настраиваемые через конфиг (`bot_username` + `promo_buttons`), по умолчанию пусто.
- Получатели — активные чаты из реестра `max_chats` (расширяемо через `BroadcastRecipientsResolver`).
- Права по умолчанию: `broadcasts.view` / `broadcasts.create` / `broadcasts.send` / `broadcasts.manage`.
- Blade-вьюхи и real-time-прогресс (Reverb/Echo) на текущем этапе не реализуются.

## Отклонения / заметки
- Рабочий план ведётся во временном `PLAN-filament-max-broadcasts.md`; после реализации его содержимое (чек-лист,
  журнал) переносится в `.ai/progress/`, а сам файл удаляется и в git не попадает.
